# Design tokens (use these in Figma styles and in style.css)

| Token | Value | Use |
| --- | --- | --- |
| Accent | #0072B2 (dark mode #56B4E9) | Bars, links, selected buttons |
| Warning | #B34700 | Values needing attention |
| Good | #00755E | Positive change |
| Ink / Muted | #1B2B24 / #5B6675 | Text |
| Surface / Background | #FFFFFF / #F6F7F9 | Cards / page |
| Font | system-ui (Inter in Figma) | 15 px body, 22 px page title, 26 px KPI value |
| Radius / Spacing | 12 px cards, 8 px controls; 16 px and 24 px gaps | Layout |

Figma steps: 1) New design file. 2) Drag wireframes_figma_ready.svg into the canvas (it arrives as editable vector layers). 3) Create color and text styles from the table. 4) Duplicate each frame and make a mid-fidelity version. 5) Share the Figma link or screenshot the frames into your presentation.
